# Ai-Aether

Real-time sales meeting assistant: mic → Whisper → Claude → Salesforce → live dashboard.

## What it does

Ai-Aether listens to your microphone during a sales call and automatically:

1. **Transcribes** audio in near-real-time using OpenAI Whisper (default) or an on-device model.
2. **Detects topic shifts** — Claude reads each transcript chunk and decides whether the conversation has moved to a new customer, deal, or subject.
3. **Extracts CRM entities** — Claude (Haiku) pulls out customer name, contact, deal amount, stage, and keywords from every chunk.
4. **Queries Salesforce** — matching Accounts and Opportunities are fetched via the REST API using OAuth 2.0.
5. **Updates a live dashboard** — all panels (transcript, entities, charts, Salesforce records) stay pinned to the current topic and refresh automatically.

## Quick start

```
cd meeting-assistant
bash setup.sh          # macOS / Linux
.\setup.ps1            # Windows PowerShell
```

Then:

```
source .venv/bin/activate   # Windows: .\.venv\Scripts\Activate.ps1
python app.py
```

Open <http://127.0.0.1:8000> and click **Connect to Salesforce** to authorise.

## Required credentials

| Credential | Purpose |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude — topic-shift detection **and** CRM entity extraction. |
| `OPENAI_API_KEY` | Required only when `WHISPER_BACKEND=openai` (the default). Not needed when using the local Whisper backend. |
| `SF_CLIENT_ID` / `SF_CLIENT_SECRET` | Salesforce Connected App for OAuth 2.0. |
| `ENCRYPTION_KEY` | Fernet key that encrypts stored OAuth tokens. Auto-generated by the setup script if left blank. |

## Architecture

```
mic → Whisper transcription
    → Claude (topic shift detection)
    → Claude Haiku (CRM entity extraction)
    → Salesforce REST API (accounts & opportunities)
    → WebSocket → browser dashboard
```
